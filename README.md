# Compra con Cabeza

Sitio estático en español con guías prácticas de organización del hogar.

## Publicación
El workflow de GitHub Actions publica el contenido con GitHub Pages cuando Pages está configurado para usar **GitHub Actions** como fuente.

URL prevista: https://juanrasines496-hub.github.io/compra-con-cabeza/

## Antes de promocionarlo
- Completar `legal.html` con los datos reales del titular y revisar las obligaciones aplicables.
- Revisar cada artículo y mantener actualizados los consejos.
- Si se aprueba una cuenta de afiliación, añadir los identificadores y avisos requeridos por el programa correspondiente. Los enlaces actuales son búsquedas generales y no generan comisiones.
- Verificar la URL pública y el sitemap después de la primera publicación.

No se garantiza tráfico ni ingresos.
